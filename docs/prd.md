## 1. 产品概述

### 1.1 产品名称

**AI Image Checker**（暂定）

### 1.2 产品定位

一款面向海外用户的免费 AI 生成图片检测工具，通过多引擎对比检测和可视化解释报告，帮助用户快速判断图片是否由 AI 生成。

### 1.3 一句话描述

> "Upload an image, get a multi-engine AI detection result with visual explanation in seconds."

### 1.4 目标用户

| 用户群体 | 占比 | 核心需求 |
|---------|------|---------|
| 教师/学生 | 40% | 检测学术作品中的AI生成图片 |
| 内容创作者/媒体 | 30% | 验证图片真实性，防止虚假信息 |
| 普通用户 | 30% | 好奇心驱动，快速验证 |

### 1.5 核心价值主张

1. **多引擎对比**：同时调用多个AI检测引擎，给出综合评分，比单一引擎更准确
2. **可视化解释**：热力图标注图片中可能由AI生成的区域，结果可解释
3. **完全免费**：基础功能永久免费，无需注册
4. **极简体验**：3秒内出结果，用完即走

## 2. 市场背景

### 2.1 市场机会

- AI 图片检测赛道月搜索量预估 10万+，且持续增长
- 竞品体验差（误判率高、结果不可解释），存在差异化空间
- 有机搜索是核心获客渠道，SEO 友好
- 变现模式清晰（Freemium + 广告 + API）

### 2.2 竞品分析

| 竞品 | 月访问量 | 核心问题 |
|------|---------|---------|
| WasItAI (34.2万) | 单引擎，无解释 |
| AIorNot (20.9万) | 单引擎，流量下降 |
| Illuminarty (7.3万) | 免费额度少 |
| Sightengine (110万) | B2B定位，C端体验差 |

### 2.3 差异化策略

**我们做什么：**
- 多引擎对比（核心差异）
- 可视化热力图解释
- 免费 + 极简体验

**我们不做什么：**
- 不做企业级B2B
- 不做文本AI检测（GPTZero 太强）
- 不追求100%准确率（不可能）

### 3.2 P0 核心功能

#### 3.2.1 图片上传检测

**用户故事：**
> 作为用户，我想上传一张图片，快速知道它是否由AI生成。

**功能描述：**
- 支持拖拽上传和点击选择
- 支持格式：JPG、PNG、WebP、GIF
- 最大文件大小：20MB
- 上传后 3 秒内展示结果

**验收标准：**
- [ ] 拖拽上传正常工作
- [ ] 文件格式校验正确
- [ ] 文件大小超限给出友好提示
- [ ] 上传过程有进度指示
- [ ] 上传失败有错误提示

#### 3.2.2 多引擎对比检测

**用户故事：**
> 作为用户，我想看到多个AI检测引擎的结果对比，而不是单一引擎的判断。

**功能描述：**
- 集成 3-5 个检测引擎：
  - Hugging Face 开源模型（免费）
  - Sightengine API（付费，有免费额度）
  - Hive Moderation API（付费）
  - 自建模型（基于开源微调）
- 每个引擎独立返回检测结果
- 计算综合评分（加权平均）

**引擎权重建议：**
| 引擎 | 权重 | 说明 |
|------|------|------|
| 自建模型 | 35% | 核心引擎，可优化 |
| Hugging Face | 25% | 免费，覆盖面广 |
| Sightengine | 20% | 专业级 |
| Hive | 20% | 企业级 |

**验收标准：**
- [ ] 至少集成 3 个检测引擎
- [ ] 每个引擎独立返回结果
- [ ] 综合评分计算正确
- [ ] 引擎失败时不影响其他引擎
- [ ] 单引擎超时时给出提示

#### 3.2.3 综合评分展示

**用户故事：**
> 作为用户，我想一目了然地看到图片是否AI生成的综合判断。

**功能描述：**
- 综合评分：0-100 分
  - 0-30：大概率真实图片
  - 31-70：不确定
  - 71-100：大概率AI生成
- 每个引擎的独立评分
- 置信度指示（高/中/低）
- 简短文字说明

**UI 设计要求：**
- 评分用颜色区分：绿色（真实）→ 黄色（不确定）→ 红色（AI生成）
- 引擎结果用卡片展示
- 整体布局清晰，3秒内能看懂

**验收标准：**
- [ ] 综合评分计算正确
- [ ] 颜色编码符合直觉
- [ ] 每个引擎结果独立展示
- [ ] 置信度指示清晰
- [ ] 移动端展示正常

#### 3.2.4 URL 粘贴检测

**用户故事：**
> 作为用户，我想直接粘贴图片URL进行检测，而不需要先下载图片。

**功能描述：**
- 支持粘贴图片直链URL
- 支持常见社交平台图片URL（Twitter、Reddit、Instagram）
- 自动下载图片并进行检测
- URL无效时给出友好提示

**验收标准：**
- [ ] 图片直链URL正常工作
- [ ] 社交平台URL解析正确
- [ ] URL无效给出明确提示
- [ ] 下载超时有错误处理

### 3.3 P1 增强功能

#### 3.3.1 热力图可视化

**用户故事：**
> 作为用户，我想看到图片中哪些区域被判定为AI生成，而不只是一个整体分数。

**功能描述：**
- 在原图上叠加热力图
- 红色区域 = 高概率AI生成
- 绿色区域 = 大概率真实
- 支持缩放查看细节
- 支持下载热力图

**验收标准：**
- [ ] 热力图准确标注AI区域
- [ ] 支持缩放和拖拽
- [ ] 可下载热力图
- [ ] 性能不影响页面加载

#### 3.3.2 检测历史记录

**用户故事：**
> 作为用户，我想查看我之前检测过的图片和结果。

**功能描述：**
- 本地存储（localStorage）
- 保存最近 50 条检测记录
- 支持查看历史详情
- 支持清除历史

**验收标准：**
- [ ] 历史记录正确保存
- [ ] 可查看历史详情
- [ ] 可清除历史
- [ ] 不影响页面性能

#### 3.3.3 结果分享

**用户故事：**
> 作为用户，我想分享检测结果给他人。

**功能描述：**
- 生成分享链接
- 分享页面展示检测结果
- 支持复制链接
- 支持分享到社交媒体

**验收标准：**
- [ ] 分享链接可访问
- [ ] 分享页面展示完整结果
- [ ] 复制链接功能正常
- [ ] 社交分享跳转正确

### 3.4 P2 扩展功能

#### 3.4.1 浏览器扩展

**用户故事：**
> 作为用户，我想在浏览器中右键点击任何图片，直接进行AI检测。

**功能描述：**
- Chrome/Firefox 扩展
- 右键菜单"Check if AI generated"
- 弹出检测结果面板

**验收标准：**
- [ ] Chrome 扩展正常安装和使用
- [ ] 右键菜单正常工作
- [ ] 检测结果面板展示正确

#### 3.4.2 视频检测

**用户故事：**
> 作为用户，我想检测视频是否由AI生成。

**功能描述：**
- 支持上传视频文件
- 支持粘贴视频URL
- 抽帧检测（每秒1帧）
- 展示每帧检测结果和综合评分

**验收标准：**
- [ ] 视频上传正常工作
- [ ] 抽帧检测逻辑正确
- [ ] 结果展示清晰
- [ ] 大文件有进度提示

#### 3.4.3 API 接口

**用户故事：**
> 作为开发者，我想通过API调用AI图片检测功能。

**功能描述：**
- RESTful API
- 支持图片URL和Base64输入
- 返回JSON格式结果
- API Key 认证

**验收标准：**
- [ ] API文档完整

- [ ] 有速率限制
